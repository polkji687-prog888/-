# دعم فهم الصور في فريدة

## النتيجة

لم يتم تفعيل رفع الصور إلى خادم رؤية في هذا التغيير. السبب أن البحث الموثوق عن خدمة رؤية عامة مجانية بلا مفتاح API تعذر بسبب نفاد حصة البحث، كما أن أي خدمة عامة بلا مفتاح لا يمكن اعتمادها بأمان كافتراض: قد تتغير حدودها أو شروطها أو تتوقف، وقد ترسل صور المستخدم إلى طرف ثالث.

لذلك لا يجوز الادعاء بأن اختيار صورة وحده يعني أن فريدة تفهم محتواها.

## أفضل بديل مجاني

البديل الموصى به هو **تحليل الصور على الجهاز** باستخدام مكتبات أندرويد المجانية/مفتوحة المصدر، مثل:

- ML Kit Image Labeling على الجهاز للتصنيفات العامة.
- ML Kit Text Recognition لاستخراج النص من الصور.
- نموذج TensorFlow Lite أو MediaPipe محلي، إذا تم تضمين نموذج مرخّص واختباره داخل التطبيق.

هذه الخيارات لا تحتاج إلى مفتاح مدفوع ولا ترسل الصورة خارج الجهاز، لكنها ليست نموذج محادثة بصريًا عامًا بالضرورة. قد تعطي تسميات أو نصًا فقط، وقد تختلف الدقة واللغات وحجم التطبيق بحسب النموذج.

## ما يلزم قبل التنفيذ

1. قراءة ملفات أندرويد وGradle الحالية فعليًا، لأن محتوى الملفات لم يكن متاحًا؛ أداة القراءة أعادت روابط مؤقتة بدل bytes.
2. اختيار مكتبة وإصدار متوافقين مع toolchain المشروع.
3. إضافة زر اختيار صورة عبر `ACTION_OPEN_DOCUMENT` مع الاحتفاظ بالسلوك الحالي.
4. عرض الصورة محليًا فقط.
5. طلب موافقة عربية واضحة قبل أي إرسال خارجي، ومنع الإرسال افتراضيًا.
6. عند عدم وجود محرك محلي أو نقطة نهاية يحددها المستخدم، عرض رسالة عربية واضحة بدل اختلاق نتيجة.

## حدود الخصوصية

إذا اختار المستخدم لاحقًا نقطة نهاية رؤية مستضافة ذاتيًا أو مجانية، يجب عرض عنوانها وشروطها، والحصول على موافقة منفصلة لكل إرسال. لا يجب وضع مفتاح سري داخل التطبيق، ولا يجب إرسال الصور أو الذاكرة دون موافقة صريحة.

## المصادر المرجعية

- Android document picker: https://developer.android.com/reference/android/content/Intent#ACTION_OPEN_DOCUMENT
- ML Kit Image Labeling: https://developers.google.com/ml-kit/vision/image-labeling
- ML Kit Text Recognition: https://developers.google.com/ml-kit/vision/text-recognition
- TensorFlow Lite: https://www.tensorflow.org/lite
- MediaPipe Tasks: https://ai.google.dev/edge/mediapipe/solutions/guide

هذه الوثيقة لا تزعم أن أي endpoint عام مجاني متاح حاليًا، ولا تزعم أن دعم الصور أصبح موجودًا في التطبيق.
